# ⚾ 가을야구 자동 예매

정해진 시각(KRISS 표준시 기준)에 NOL 티켓 포스트시즌 페이지의 **"예매하기" 버튼을 자동으로 클릭**하는 로컬 웹앱입니다.
클릭 이후(좌석 선택, 보안문자, 결제)는 직접 진행합니다.

## 실행

`start.bat` 을 더블클릭하세요. 처음 실행하면 패키지를 설치한 뒤 브라우저에서 http://localhost:4300 이 열립니다.
(명령어로는 `npm install` 다음에 `npm start`)

필요한 것: Node.js 18 이상, Google Chrome

## 사용 순서

1. **브라우저 열기**를 누르면 전용 크롬 창이 열립니다. **처음 한 번은 이 창에서 직접 로그인**하세요.
   로그인 정보는 `browser-profile` 폴더에 저장되어 다음 실행부터 유지됩니다.
   (구글 로그인은 자동화 브라우저에서 막힐 수 있으니 카카오·네이버·이메일 로그인을 권장합니다.)
2. **경기 불러오기**를 누른 뒤 목록에서 경기를 고릅니다.
3. **예매 오픈 날짜·시각**(한국 시간, 초 단위)을 입력합니다.
4. **실행**을 누르고 기다립니다. 전용 크롬 창은 건드리지 마세요(스크롤하면 클릭 위치가 어긋날 수 있습니다).

## 동작 방식

| 시점 | 동작 |
|---|---|
| 실행 시 | KRISS(time.kriss.re.kr) 시간 서버로 PC 시계 오차 측정 |
| 오픈 60초 전 | 페이지 새로고침 1회 → 버튼 상태가 안정될 때까지 대기 → 시간 재동기화 |
| 그 직후 | 버튼 상태 감시 시작 (`disabled` 해제 등 변화 감지) |
| 오픈 1초 전부터 | 0.1초 간격 반복 클릭 |
| 버튼 활성화 순간 | 감지 즉시 추가 클릭 (테스트 기준 수 ms 이내) |
| 새 창/페이지 이동 | 성공으로 보고 중단 → 이후 직접 진행 |
| 오픈 후 10초 | 이동이 없으면 중단 |

- 클릭은 실제 마우스 입력(신뢰된 이벤트)으로 보내므로 팝업 차단에 걸리지 않습니다.
- 오픈 전 알림창("오픈 전입니다" 등)은 자동으로 닫습니다.
- 로그인 페이지로 이동하면 "로그인 필요"로 표시하고 중단합니다.
- 고급 설정에서 클릭 시작 시점, 간격, 최대 시도 시간, 새로고침 시점을 바꿀 수 있습니다.

## ⚠️ PC 시계

사이트가 PC 시계를 보고 버튼을 활성화한다면, PC 시계가 늦은 만큼 버튼도 늦게 열립니다.
화면 상단에 오차가 50ms 이상으로 표시되면 Windows 시계를 맞추세요:
제어판 → 시계 및 국가 → 날짜 및 시간 → 인터넷 시간 → 설정 변경 → 서버 `time.kriss.re.kr` → 지금 업데이트

## 테스트

http://localhost:4300/test.html 은 연습용 가짜 예매 페이지입니다.
- `test.html?in=20` : 페이지를 연 뒤 20초 후 4차전 버튼이 활성화 (class 방식)
- `test.html?in=20&mode=disabled` : 실제 사이트처럼 `disabled` 속성 방식

웹앱의 URL 칸에 이 주소를 넣고, 오픈 시각을 "지금 + 약 20초"로 넣어 실행해 보면 동작을 확인할 수 있습니다.
(사전 새로고침을 켜면 테스트 페이지의 타이머가 초기화되므로 테스트할 때는 0으로 두세요.)

## 주의

- 예매 사이트 약관상 자동화 도구 사용은 계정 제재 사유가 될 수 있습니다.
- 매크로로 구매한 티켓의 재판매는 공연법·국민체육진흥법상 처벌 대상입니다. 본인 관람용으로만 사용하세요.
